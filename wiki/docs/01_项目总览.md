# 01 项目总览

## 基本信息

| 项目 | 内容 |
|------|------|
| 项目名称 | 沉陷区的地质记忆——徐州采空塌陷区地质演化与人地关系调查研究 |
| 团队名称 | 中国地质大学（北京）徐州贾汪区社会实践团 |
| 团队编号 | 2026010109（校组织项目编号 szxm-2026-0127） |
| 实践选题 | 主题一：共话二十大，走深学笃行之路 |
| 实践时间 | 2026 年 8 月下旬（7 天） |
| 实践地点 | 江苏省徐州市贾汪区：大吴街道采空塌陷区（未修复）+ 潘安湖国家湿地公园（已修复） |
| 组织单位 | 地球科学与资源学院 |
| 团队规模 | 12 名学生（11 名大一 + 1 名大二）+ 1 名随团指导教师 |

## 选题依据

1. **专业高度契合**：塌陷区治理与地质学高度契合，团队全部为地院学生，已完成《地球科学概论》与北戴河野外地质实习。
2. **社会价值明确**：采空塌陷区治理是国家生态修复重点，大学生深入调查能为地方政府提供多重视角，助力资源型地区绿色转型。
3. **差异化竞争优势**：以"地质记忆"概念为核心视角，将地质变化理解为嵌入居民生命经验的集体记忆载体，桥接自然科学与社会科学。

## 研究框架

"调查—问题—解决方案"三段式框架，地质学与人文地理学双重视角：

- **地质调查**：描述性方法为核心，建立涵盖地层特征、构造形迹、地貌演化、岩石露头描述的**四维地质档案**，绘制地层柱状图、构造素描图、地貌剖面图。
- **人文调查**：围绕"人地关系"，通过半结构化访谈、问卷调查、参与式观察，了解居民生计转型、搬迁适应、环境感知与地方认同变化，采集口述史。

## 项目特色

1. **地质学视角的专业性**——课堂知识转化为现场分析能力，"知行合一"。
2. **多学科交叉的综合性**——"地质记忆"概念桥接自然科学与社会科学。
3. **人文关怀的温度**——关注妇女、儿童、老年群体，以口述史记录矿业社区集体记忆。
4. **空间对比强烈**——大吴街道（未修复原始塌陷地貌）× 潘安湖（国家湿地公园），构成"创伤—修复—重生"完整链条。
5. **双片影像实证**——长纪录片（30–40 分钟）+ 短宣传片（2–4 分钟）协同创作。
6. **现场调研深度**——7 天现场调研、100 份以上问卷、18 份以上深度访谈，区别于同类高校 1–3 天参观式调研；开展"数据核查型调研"，报告设数据底账附录（见 数据口径核查（内部资料））。

## 项目意义

- **学术层面**：以"地质记忆"探索采煤塌陷区地质演化与人地关系的互动机制，为资源型地区人地关系研究提供大学生视角的实证补充。
- **社会层面**：总结贾汪综合治理经验与挑战，为同类地区生态修复与社区重建提供参考；宣传潘安湖典型案例。
- **育人层面**：专业训练闭环 + 家国情怀培养。
